## Alternatives Considered

- **Tracked .gitignore**: git documentation says patterns all developers want ignored belong in .gitignore and travel via clone; https://git-scm.com/docs/gitignore (manual last updated in Git 2.55.0, 2026-06-29; read 2026-10-17).
- **Repository info/exclude**: the same page places patterns specific to one user's workflow in $GIT_COMMON_DIR/info/exclude; https://git-scm.com/docs/gitignore (Git 2.55.0, 2026-06-29).
- **Subdirectory plugin root (source ./plugins/review-code)**: stops .planning/ and docs/ from shipping; relative plugin sources per https://code.claude.com/docs/en/plugin-marketplaces (read 2026-10-17); contradicts locked D-03.

Decided by: simplicity (no layout change and no new tracked logic); the final pick is the user's at Task 1.
